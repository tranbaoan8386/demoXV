1. Module 1: Identity & SSO Service (Viết bằng Go)
Mục tiêu: Áp dụng kiến thức SSO và Clean Architecture (Go).

Nhiệm vụ:

Đóng vai trò Identity Provider (IdP) / Auth Gateway hỗ trợ OAuth2 / OIDC.

Tích hợp SSO trực tiếp với LibreChat (để khi dùng LibreChat, người dùng đăng nhập qua SSO Service này).

Kiến trúc (Clean Arch đơn giản):

domain/: User, Session, Token entities.

usecase/: Login, ValidateToken, IssueSSOToken.

repository/: Postgres store.

delivery/http/: Gin / Fiber handlers.

2. Module 2: Document Processing Engine (Viết bằng Go)
Mục tiêu: Tối ưu hiệu năng xử lý file, tái sử dụng cho nhiều dự án sau này (đúng góp ý của mentor).

Nhiệm vụ:

Nhận file (PDF, DOCX, XLSX, Image).

Trích xuất văn bản (Text extraction), phân trang, chunking, và OCR (nếu là ảnh).
*expose qua API (REST/gRPC) để service khác gọi.

Kiến trúc (Clean Arch):

Tách riêng adapter cho từng loại parser (Py/Go native PDF parser, Tesseract/Vision OCR adapter, Docx adapter).

3. Module 3: Business Domain & AI Service (Viết bằng Python)
Mục tiêu: Thực hành DDD (Domain Driven Design) mức độ đơn giản và Clean Architecture trong Python.

Nhiệm vụ:

Bounded Context 1: Document Management (Lưu trữ, tạo Embedding, Semantic Search).

Bounded Context 2: Contract Risk Audit (Tập hợp quy tắc kiểm tra rủi ro hợp đồng, pháp lý, điều khoản thanh toán, phạt vi phạm).

Ứng dụng DDD đơn giản:

Entities/Value Objects: Contract, RiskRule, AuditReport, Clause.

Domain Service: ContractAnalyzerService (Chứa logic kết hợp prompt, RAG và kiểm tra điều khoản).

Repository: Interface lưu lưu trữ vector (Qdrant/Milvus/pgvector) và DB metadata.

4. Giao diện & Trải nghiệm: LibreChat Integration
Mục tiêu: Áp dụng LibreChat mà không cần tốn thời gian code lại Frontend từ đầu.

Nhiệm vụ:

Cấu hình LibreChat dùng SSO Service (Go) đã viết ở Module 1.

Cấu hình Custom Endpoints / Plugin / Tools trong LibreChat kết nối với Python AI Service để người dùng có thể chat trực tiếp: "Hợp đồng A có điều khoản phạt nào rủi ro không?".
